# Export Shipment Analytics - Power BI

## Project Overview

This project focuses on tracking export shipment progress using Power BI.

I built the dashboard to compare contracted quantities with actual shipped quantities and remaining quantities, making it easier to follow shipment progress across different products and items.

## Dashboard Overview

The dashboard provides a summary of shipment performance and allows users to filter the analysis by product.

Key metrics include:

- Total Contract Quantity
- Actual Shipped Quantity
- Remaining Quantity
- Actual Shipped %
- Total Number of Items

![Export Shipment Dashboard](Export_Shipment_Dashboard.png)

## Shipment Analysis

The dashboard provides item-level analysis to compare planned quantities with actual shipments.

The analysis includes:

- Contract quantity by item
- Actual shipped quantity by item
- Remaining quantity
- Shipment completion percentage
- Shipped vs. remaining quantities
- Item-level shipment performance

Product filters allow the user to focus on specific product categories and review their shipment status separately.

## Tools Used

- Power BI
- Power Query
- DAX
- Data Modeling
- Data Cleaning and Transformation
- Data Visualization

## What I Worked On

For this project, I prepared the shipment data and created the calculations needed to track shipment progress against contracted quantities.

I also built the dashboard and product filters to make it easier to identify completed, partially shipped, and remaining quantities at both overall and item level.
